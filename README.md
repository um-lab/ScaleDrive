# ScaleDrive project page

Static academic project page for **Scaling Action-Free Video Latent Prediction for Transferable Representations in End-to-End Autonomous Driving**.

The page presents the abstract, overview figure, result comparisons, and closed-loop videos. It does not include the paper PDF.

To publish with GitHub Pages, use the `main` branch and `/ (root)` as the source. The expected URL is <https://um-lab.github.io/ScaleDrive/> after Pages is enabled for this repository.

The layout draws inspiration from the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template) and [Nerfies](https://github.com/nerfies/nerfies.github.io).
